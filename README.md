# Yay Garage

Website showroom motor trail responsif untuk Yay Garage.

## Fitur
- Menambah, mengedit, dan menghapus produk motor
- Upload foto motor dari perangkat
- Menyimpan data secara otomatis di browser (`localStorage`)
- Pencarian motor
- Filter berdasarkan tipe
- Tampilan katalog responsif untuk desktop dan mobile

## Menjalankan
Buka `index.html` langsung di browser atau gunakan GitHub Pages.
